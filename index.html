OTT Subscription Management System

Tech: Java, Java Swing, JDBC, MySQL

Integrated Java Swing for the graphical interface and JDBC for database connectivity with MySQL. Source on GitHub

Load Balancer Simulator

Tech: Java, Data Structures, Algorithms (DSA)

Developed a Java-based load balancer simulator to demonstrate efficient distribution of incoming requests across multiple servers. Implemented Round Robin and Least Load scheduling algorithms, along with server failure and recovery, request queuing and autoscaling. Used custom data structures including dynamic arrays, linked queues, stacks, hash tables and binary heaps.

Source on GitHub
